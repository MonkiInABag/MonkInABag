## 🔨 Featured Builds

### 🤖 Buddi

**Desktop Companion Robot**

ESP32-based desktop companion robot combining embedded hardware, animated displays, movement and local AI integration.

`ESP32` `C++` `MQTT` `Robotics` `CAD`

---

### 🖱️ Touch Mouse

**Custom Capacitive-Touch Mouse**

Custom mouse built around an ESP32-S3 with capacitive touch scrolling, physical controls and a custom 3D-printed enclosure.

`ESP32-S3` `C++` `Capacitive Touch` `Electronics` `3D Printing`

### 🐚 E-Shell

**Modular Laptop Accessory System**

A modular mounting system for attaching interchangeable accessories to a laptop, designed around custom 3D-printed attachments.

`Fusion 360` `CAD` `3D Printing` `Product Design`

Compact handheld device designed for robotics, electronics and embedded development, with onboard controls and expandable hardware interfaces.

`ESP32-S3` `Embedded Systems` `Electronics` `UI` `CAD`
